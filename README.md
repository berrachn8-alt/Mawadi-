# Mawadi - موادّي

أول سوق وطني لمواد البناء في الجزائر

## النشر على Vercel
1. فك ضغط هذا الملف
2. ارفع الملفات اللي داخلو (index.html, package.json, vercel.json, vite.config.ts, tsconfig.json, src/) في GitHub Repo mawadi
3. في Vercel: Import Git Repository -> mawadi -> Deploy

ملاحظة: لا ترفع ملف ZIP نفسه في Vercel، ارفع الملفات المفكوكة في GitHub.
